## Status definitions

- SUPPORTED: reproduced successfully in the stated environment.
- CONDITIONAL: works with documented restrictions.
- REJECTED: a known requirement cannot be met safely.
- UNKNOWN: insufficient evidence.

A result on one platform does not imply support on another. A platform row must name the actual tested build, not only a project branch or marketing version.
